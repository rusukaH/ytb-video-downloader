# YTB Video Downloader

Baixa vídeos do YouTube em MP4 (H.264) e MP3, com prévia, forma de onda e corte de trechos.

## Instalar no Windows

1. Abra a [última versão](https://github.com/rusukaH/ytb-video-downloader/releases/latest) e baixe **YTB-Video-Downloader-vX.Y.Z.zip**.
2. Extraia o ZIP (botão direito > Extrair tudo).
3. Dê dois cliques em **Instalar.cmd** e clique em **Instalar**.

Depois de instalado, o app se atualiza sozinho a partir das versões publicadas aqui.
